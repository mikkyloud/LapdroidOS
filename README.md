# LapdroidOS

An Android-style emulator built with JavaScript, with a Play Store-style app installer.

**Live demo:** [lapdroid-os.vercel.app](https://lapdroid-os.vercel.app)

## About
LapdroidOS is my first project. I built it to learn how app interfaces and operating system features can be recreated with code, and it taught me the basics of JavaScript, building interfaces, and deploying a live project.
